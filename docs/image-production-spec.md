# TasteDNA 이미지 제작 통합 명세

## 1. 문서 목적

본 문서는 TasteDNA의 이미지 기반 질문에 사용되는 정식 이미지의 제작 기준, 선택지별 시각적 표현 원칙, 이미지 연결 방식 및 검수 기준을 정의한다.

TasteDNA는 기존 패션 쇼핑몰에 연동하는 취향 분석 시스템이다. 이미지의 역할은 사용자가 자신의 의류 취향을 정확하게 표현하도록 돕는 것이다.

이미지는 단순한 장식이 아니라 질문과 선택지가 의도하는 취향 차이를 표현해야 한다.

### 개발 단계 구분

**현재 — GPT와 사용자 수동 개발**

- 질문과 선택지 데이터 구현
- 답변 저장 및 검증
- 관측 규칙 및 Raw TasteDNA 분석 기반 개발
- 이미지 제작에 필요한 질문·선택지 식별 정보 정리

**후반부 — Codex와 사용자 개발**

- 이미지 기반 문항 전체 확인
- 선택지별 상세 이미지 생성 지침 작성
- 사용 가능한 이미지 생성 도구를 활용한 정식 이미지 제작
- 이미지 검수 및 필요 시 재생성
- 질문 화면과 이미지 리소스 연결
- 실제 답변 저장 및 분석 기능과의 연동 검증

별도의 임시 텍스트 PNG나 그림판용 이미지는 제작하지 않는다.

---

## 2. 이미지 제작 공통 정책

### 2.1 질문과 선택지의 의미 유지

1. 모든 이미지는 확정된 질문 정의와 선택지 ID를 기준으로 제작한다.
2. 선택지가 표현하려는 의류 특성을 시각적으로 명확하게 드러낸다.
3. 이미지가 선택지의 의미를 변경해서는 안 된다.
4. 이미지 제작을 이유로 질문 ID나 선택지 ID를 임의로 변경하지 않는다.
5. 이미지의 시각적 요소를 새로운 채점 근거로 사용하지 않는다.
6. 확정되지 않은 설계 사항은 임의로 결정하지 않는다.

### 2.2 선택지 간 비교 가능성

같은 문항의 이미지는 비교 가능한 조건으로 제작한다.

- 모델 자세와 촬영 구도를 가능한 한 일관되게 유지한다.
- 촬영 거리, 배경, 조명 등의 불필요한 차이를 줄인다.
- 질문에서 비교하려는 의류 특성이 주요 차이로 드러나도록 한다.
- 모델 외형, 배경, 소품 등의 부수적 요소가 선택에 미치는 영향을 최소화한다.
- 문항에 따라 전체 착장, 상반신 또는 의류의 특정 부분이 충분히 보이도록 구성한다.

모든 문항에 동일한 구도를 무조건 적용하지 않는다. **비교하려는 취향 특성이 가장 명확하게 드러나는 구도**를 선택한다.

### 2.3 이미지와 백엔드 기능 분리

이미지 파일은 질문·선택지 ID와 연결하되, 답변 판별 규칙 및 관측 규칙과 분리한다.

정식 이미지를 교체하더라도 다음 요소는 유지하는 것을 원칙으로 한다.

- 질문 ID
- 선택지 ID
- 답변 저장 구조
- 관측 규칙 연결
- 채점 및 RESULT 판별 계약

단, 교체한 이미지가 선택지의 의미를 실질적으로 변경한다면 단순 파일 교체로 처리하지 않고 설계 변경 여부를 검토한다.

### 2.4 이미지 파일 관리

이미지 파일 형식, 크기, 비율, 저장 경로 및 파일명 규칙은 실제 질문 화면 구조를 확인한 후 확정한다.

파일명에는 가능한 한 다음 정보를 식별할 수 있도록 한다.

- 테스트 모드: Simple 또는 Deep
- 질문 ID
- 선택지 ID

이미지 제작 규격과 리소스의 실제 연결 방식은 구분하여 관리한다.

## 3. 이미지 기반 문항 식별 및 명세 작성 기준

Codex 개발 단계에서는 전체 Simple·Deep 질문 정의와 승인된 설계 문서를 확인하여 이미지가 필요한 문항을 식별한다.

이미지 문항 여부를 질문 번호만으로 추측하지 않는다.

각 문항에는 다음 정보를 정리한다.

1. **질문 정보:** 모드, 질문 ID, 확정 질문 문구
2. **선택지 정보:** 선택지 ID와 확정된 의미
3. **관측 목적:** 사용자에게 구별하거나 비교하도록 요구하는 의류 특성
4. **공통 이미지 조건:** 모델, 의류 종류, 구도, 배경 등
5. **선택지별 상세 묘사:** 해당 선택지만의 핵심 시각적 특징
6. **검수 기준:** 선택지의 의미가 정확히 표현됐는지 판단할 기준

문항별 제작 규격은 이 문서의 **7장에 질문 순서대로 계속 추가한다.**

## 4. Codex 개발 인계 지침

Codex는 이미지 관련 작업을 시작하기 전에 다음 정보를 확인한다.

- `AGENTS.md`
- 본 문서 `docs/image-production-spec.md`
- 승인된 TasteDNA 질문·선택지 설계 문서
- 실제 질문 정의 JSON
- 기존 이미지 파일 및 화면 구현 상태
- 답변 저장과 관측 규칙에 사용되는 질문·선택지 ID

### 작업 순서

1. 이미지가 필요한 질문과 선택지를 식별한다.
2. 확정된 선택지 정보를 기준으로 제작 명세를 작성한다.
3. 이미지 생성 도구를 활용하여 정식 이미지를 제작한다.
4. 사용자와 함께 이미지의 의미와 품질을 검수한다.
5. 승인된 이미지 파일을 프로젝트에 등록한다.
6. 실제 질문 화면에서 선택지와 이미지를 연결한다.
7. 이미지 로딩, 선택 동작, 답변 저장을 확인한다.
8. 이미지 변경 전후의 질문·선택지 ID 및 관측 규칙 연결을 검증한다.

이미지 생성 도구를 사용할 수 없거나, 선택지의 시각적 의미가 불명확하다면 임의의 이미지를 확정하지 않고 해당 작업을 미완료로 보고한다.

## 5. 정식 이미지 검수 기준

이미지 제작이 완료되면 다음 조건을 확인한다.

- 이미지가 해당 선택지의 의미를 정확히 표현하는가?
- 같은 질문의 다른 이미지와 비교하기 쉬운가?
- 사용자의 선택을 왜곡할 만한 불필요한 시각적 차이가 있는가?
- 의류의 핵심 특징이 화면 크기가 작아져도 구별되는가?
- 이미지와 질문·선택지 ID가 정확하게 대응되는가?
- 이미지가 정상적으로 표시되고 선택할 수 있는가?
- 이미지 교체 후에도 답변 저장 및 관측 기능이 정상적으로 동작하는가?

위 조건을 충족하지 못하면 이미지 수정 또는 재생성을 검토한다.

---

## 6. 이미지 제작 완료 기준

다음 조건을 모두 충족했을 때 이미지 작업을 완료한 것으로 판단한다.

1. 이미지 기반 질문의 대상 선택지가 식별되어 있다.
2. 대상 선택지별 정식 이미지가 제작되어 있다.
3. 이미지가 실제 질문 화면에 정상 표시된다.
4. 사용자가 이미지를 선택하고 답변을 저장할 수 있다.
5. 이미지와 선택지 ID의 대응 관계가 정확하다.
6. 기존 관측 규칙 및 분석 로직과 충돌하지 않는다.
7. 이미지가 설계된 취향 특성을 표현하는지 검수되었다.

# 7. 문항별 정식 이미지 제작 규격

이 장에는 실제 이미지 제작이 필요한 문항의 규격을 질문 순서대로 누적한다.

현재 작성된 Q3·Q4의 제작 기준은 초기 기준이며, 선택지별 상세 생성 지침과 최종 이미지 파일은 Codex 개발 단계에서 완성한다.

## 7.1 Simple Q3 — 핏·실루엣 선호

### 질문 정보

- 질문 ID: `Q03`
- 질문: 옷을 입었을 때 어떤 핏이나 실루엣이 가장 마음에 드나요?
- 질문 유형: `MULTIPLE_CHOICE`
- 최대 선택 수: 3개

### 선택지

| ID | 선택지 |
|---|---|
| S01 | 슬림핏 |
| S02 | 레귤러핏 |
| S03 | 릴랙스드핏 |
| S04 | 오버사이즈핏 |
| S05 | 짧고 컴팩트한 실루엣 |
| S06 | 길고 여유로운 실루엣 |

### 공통 제작 기준

- 옷의 핏과 전체 비율을 비교할 수 있는 착장 이미지를 제작한다.
- 비교 가능한 의류 종류, 모델 자세, 촬영 거리 및 배경을 사용한다.
- 색상과 액세서리의 차이가 핏 선택을 방해하지 않도록 한다.
- 몸과 의류 사이의 여유 공간, 착장의 길이와 비율이 식별되도록 한다.

### 선택지별 핵심 표현

**S01 — 슬림핏**

몸의 윤곽을 비교적 가깝게 따라가는 의류 핏을 표현한다. 과도하게 몸을 압박하거나 특정 체형 자체를 강조하는 이미지가 되지 않도록 한다.

**S02 — 레귤러핏**

몸에 지나치게 밀착하거나 넓지 않은 일반적인 여유의 핏을 표현한다. 슬림핏 및 릴랙스드핏과의 차이를 확인할 수 있어야 한다.

**S03 — 릴랙스드핏**

레귤러핏보다 여유가 있지만 과도하게 크지 않은 자연스러운 실루엣을 표현한다.

**S04 — 오버사이즈핏**

의도적으로 넉넉하게 설계된 의류의 전체 형태를 표현한다. 단순히 모델에게 큰 사이즈의 옷을 잘못 입힌 것처럼 보이지 않도록 한다.

**S05 — 짧고 컴팩트한 실루엣**

전체 착장의 길이와 비율에서 짧고 간결한 형태가 명확히 드러나도록 표현한다.

**S06 — 길고 여유로운 실루엣**

상대적으로 길게 이어지는 의류의 형태와 여유로운 비율을 표현한다.

### 검수 시 주의사항

S01~S04는 주로 핏의 여유 정도를, S05~S06은 착장 길이와 전체 비율을 표현한다.

이 차이가 이미지에서도 명확하게 구분되는지 검수한다.

## 7.2 Simple Q4 — 패턴·그래픽 선호

### 질문 정보

- 질문 ID: `Q04`
- 질문: 옷에 들어간 패턴이나 그래픽 중 마음에 드는 것을 골라주세요.
- 질문 유형: `MULTIPLE_CHOICE`
- 최대 선택 수: 4개

### 선택지

| ID | 선택지 |
|---|---|
| P01 | 무지·솔리드 |
| P02 | 스트라이프 |
| P03 | 체크·격자 |
| P04 | 작은 로고·그래픽 |
| P05 | 큰 그래픽·레터링 |
| P06 | 플라워·식물 패턴 |
| P07 | 도트·반복 패턴 |
| P08 | 추상·아트 패턴 |
| P09 | 애니멀 패턴 |

### 공통 제작 기준

- 가능한 한 동일한 의류 종류를 기준으로 패턴과 그래픽 차이를 표현한다.
- 패턴이 충분히 보이도록 의류의 해당 영역을 보여준다.
- 모델 자세와 촬영 구도를 통일해 비교 가능성을 확보한다.
- 배경과 의류 색상은 패턴 비교를 방해하지 않도록 한다.
- 선택지별 패턴의 형태, 크기, 밀도 및 배치가 구별되도록 한다.

### 선택지별 핵심 표현

**P01 — 무지·솔리드**

로고나 그래픽, 반복 패턴이 없는 단색 의류의 표면을 표현한다.

**P02 — 스트라이프**

방향성이 있는 줄무늬 패턴을 명확히 표현한다. 다른 선택지와 혼동될 만한 추가 그래픽을 최소화한다.

**P03 — 체크·격자**

교차하는 선과 격자 형태의 패턴을 표현한다. 스트라이프와 시각적으로 구분되어야 한다.

**P04 — 작은 로고·그래픽**

의류의 일부에 작게 배치된 로고 또는 그래픽을 표현한다. 그래픽보다 의류의 전체 면적이 더 크게 인식되도록 한다.

**P05 — 큰 그래픽·레터링**

의류의 넓은 영역을 차지하는 그래픽이나 레터링을 표현한다. P04와의 크기 및 시각적 비중 차이가 명확해야 한다.

**P06 — 플라워·식물 패턴**

꽃, 잎사귀 또는 식물 형태의 패턴이 명확하게 드러나도록 표현한다.

**P07 — 도트·반복 패턴**

점 형태 또는 규칙적으로 반복되는 작은 요소를 표현한다. 단, 다른 특정 패턴 유형과 혼동되지 않도록 한다.

**P08 — 추상·아트 패턴**

추상적인 형태와 예술적 그래픽 구성을 표현한다. 특정 구상 패턴에 치우치지 않도록 한다.

**P09 — 애니멀 패턴**

동물의 무늬에서 유래한 패턴을 표현한다. 단순한 동물 그림이나 캐릭터 그래픽과 구분한다.

### 검수 시 주의사항

패턴 자체의 종류뿐 아니라 크기와 시각적 비중의 차이가 선택을 왜곡하지 않는지 검토한다.

특히 P04와 P05는 그래픽의 크기 차이가 핵심 구분 요소이다.

## 향후 추가할 문항

이 아래에 실제 이미지 기반 문항으로 확인된 질문을 순서대로 추가한다.

예를 들어 Q6이 이미지 문항으로 확인된다면 `7.3 Simple Q6`을 추가한다.

Simple의 나머지 이미지 기반 문항과 Deep의 이미지 기반 문항은 승인된 질문 설계를 확인한 후 작성한다.

최종 이미지 제작 및 적용 과정에서 이 장을 확장하되, 확정되지 않은 질문·선택지의 의미를 임의로 변경하지 않는다.
