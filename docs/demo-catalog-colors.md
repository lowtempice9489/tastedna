# FORM 데모 상품 색상 — 14-T3B1

V25는 기존 상품을 수정하지 않고 색상 컬렉션만 추가한다. 등록 70개, 미등록 30개. 실제 DB 적용 수가 아닌 마이그레이션 기준이다.

V13 Q01 DIRECT_COLOR_PREFERENCE / EXPLICIT_SELECTION 및 이를 복사하는 여성복 V17의 공통 계약을 사용한다. 상품명 첫 색상 단어가 Q01 표시명의 구성 어휘와 정확히 일치하는 경우만 등록했다. 이미지의 주변색·다른 착장·판매 옵션을 추정하지 않는다. 데모 상품명 근거이며 실제 판매 상품의 공식 색상 인증은 아니다. 배색 상품은 명시된 색상만 보유하며 완전한 팔레트를 뜻하지 않는다.
