## 추가 검토

현재 미분류 목록은 없다. UNISEX는 명시적 공용 등록 근거를 확보한 경우에만 추가한다. 스타일 미등록 26개는 범위 등록과 무관하게 기존 정책대로 추천에서 제외한다. 실제 MySQL 적용은 DB 환경변수가 없어 이번 작업에서 검증하지 않았다.
