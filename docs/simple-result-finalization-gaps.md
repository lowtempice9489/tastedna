# Simple 최종 판별 계약 점검 — 14-A1

## 구현 가능한 범위

현재 최종 확정 가능한 RESULT는 없다. 기존 initial-candidates의 Q02 직접 후보, 후보별 관측 보존, DEFERRED와 missingRequirements 반환은 이미 구현되어 있다. 이 작업에서는 이를 중복 구현하지 않고 실제 저장 답변→관측 수집→후보 추출 경로에서 답변 수정 후 최신 revision과 선택만 사용되는 회귀 검증을 보완했다.

근거: V8 후보 카탈로그는 CANDIDATE, V9는 Q02 직접 매핑, V10은 EXPERIMENTAL, V11은 PROPOSED, V14 및 simple_style_core_discrimination_v0.1.json은 DISCRIMINATION_NOT_VERIFIED이다. 후보 등록이나 Q02 직접 선호는 최종 확정 조건이 아니다. 카탈로그에는 현재 Style Core 12개만 등록되어 있으므로 나머지 13개 ID를 만들어내지 않는다.

## 후보별 필수 결정

공통 필요조건 A: Q01·Q03·Q04 선택과 후보의 승인된 지지/구별 관계. B: 정의별 Q05·Q06·Q10 이미지 선택, Q07 회피/NONE, Q08·Q09 단일/순위 및 순위형 미선택과 후보의 관계. C: 어떤 근거 조합이 충분한지, 복수 후보 구별 및 충돌·보류 조건. 모든 질문을 반드시 사용하자는 정책이 아니라, 사용할 근거와 제외할 근거부터 승인해야 한다는 뜻이다.

## 다음 최소 승인 단위

우선 한 후보 또는 혼동되는 후보 쌍에 대해 적용 정의 버전, 질문·옵션·관측 유형, 지지/회피/구별 관계와 확정 조건을 명시하고 확정·보류 예시 응답을 제공해야 한다. 점수·가중치는 필수 조건이 아니며 임의로 도입하지 않는다. 일반 다중선택의 미선택은 부정 근거가 아니고, 순위형의 미선택은 해당 그룹 안의 사실일 뿐 후보 회피로 자동 승격하지 않는다. 남녀 공통 Q01~Q04와 서로 다른 Q05~Q10 계약을 구분한다.

승인된 확정 조건이 없어 성공 사례 테스트는 구성할 수 없다. 지원하지 않는 VERIFIED 설정 거부, 단일·복수 후보 보류, 최신 저장 답변 기반 재현성, 제출·소유권 보호는 기존 Java 테스트로 확인한다. API·Raw·상품 매칭·질문·Flyway는 변경하지 않는다.

## R01·R02 관측 관계 대조 — 14-A2

결론: 확인된 계약으로는 두 후보 모두 최종 확정할 수 없다. Q02 초기 후보와 다른 질문의 실제 관측은 이미 보존되므로 새 분석 계층이나 중복 구현을 추가하지 않는다. 아래의 제안 관계를 승인된 판별 규칙으로 승격하지 않는다.

확인 근거는 V9~V11·V13·V14·V17의 정의, `dev/fixtures/result/simple_style_core_attribute_mapping_v0.1.json`, `simple_style_core_discrimination_v0.1.json`, 비교 메타데이터 및 기존 `SimpleInitialCandidateService`·`SimpleCandidateDiscrimination`이다. 별도 RESULT 설계 v1.0 원문은 이번 확인 범위에서 찾지 못했으므로 읽었다고 간주하지 않는다.

| 후보 | 사용 가능한 질문·옵션과 실제 관측 | 현재 후보 관계와 승인 상태 | 최종 판별을 막는 정확한 조건 | 최소 추가 승인 사항 |
|---|---|---|---|---|
| R01 Minimal | Q02 R01 → DIRECT_FASHION_LOOK_PREFERENCE / EXPLICIT_SELECTION | 명시적 직접 선호로 초기 R01 생성 가능 | 직접 선택 자체는 최종 확정 조건이 아님 | Q02 외 어떤 관측 조합이 R01 확정에 충분한지 명시 |
| R01 Minimal | Q03 S02 레귤러핏, S03 릴랙스드핏, S04 오버사이즈핏 → DIRECT_SILHOUETTE_PREFERENCE | V11 PROPOSED의 COMPATIBLE; S02도 고유 특징이 아니라고 명시 | 양립 가능성은 R02 배제 또는 R01 구별 근거가 아님 | 이 중 사용할 옵션의 R01 지지/구별 관계 및 R02와 함께 선택됐을 때의 조건. 고유성이 없다면 구별 근거에서 제외 |
| R01 Minimal | Q04 P01 무지·솔리드, P04 작은 로고·그래픽 → DIRECT_PATTERN_GRAPHIC_PREFERENCE | P01은 제안된 SHARED_SUPPORT, P04는 COMPATIBLE | P01은 두 후보 공통이며 P04도 R01과 충돌한다고 볼 수 없음 | 별도의 검증된 구별 관측 지정; P01/P04만으로 R01 우선 확정하지 않음 |
| R02 Modern | Q02 R02 → DIRECT_FASHION_LOOK_PREFERENCE / EXPLICIT_SELECTION | 명시적 직접 선호로 초기 R02 생성 가능 | 직접 선택 자체는 최종 확정 조건이 아님 | Q02 외 어떤 관측 조합이 R02 확정에 충분한지 명시 |
| R02 Modern | Q03 S05 짧고 컴팩트한 실루엣, S03 릴랙스드핏, S04 오버사이즈핏 → DIRECT_SILHOUETTE_PREFERENCE | V11 PROPOSED의 COMPATIBLE; S05도 고유 속성이 아니라고 명시 | S05 선택만으로 R01과 구별할 수 없음; S03/S04는 양쪽에 존재 | 사용할 옵션과 R02 지지/구별 관계 및 동시 후보 처리 조건. S05를 자동 확정 조건으로 사용하지 않음 |
| R02 Modern | Q04 P01 무지·솔리드, P04 작은 로고·그래픽 → DIRECT_PATTERN_GRAPHIC_PREFERENCE | P01은 제안된 SHARED_SUPPORT, P04는 COMPATIBLE | 공통/양립 관계일 뿐 후보 고유 판별 조건이 아님 | R01과 동일하게 별도의 검증된 구별 관측 및 충분성 조건 필요 |

Q03·Q04의 직접 선호 사실 자체는 승인된 질문 계약이다. 위 후보 연결은 별개이다. V10 및 속성 fixture는 EXPERIMENTAL, 후보 프로필은 PROPOSED이며 `allowFinalClassification=false`이다. V11 관계는 과거 정의 `22222222-2222-4222-8222-222222222222`에 속한다. 현재 남성복 V13과 여성복 V17의 Q01~Q04가 공통이어도 이 제안 관계를 현재 정의의 검증된 판별 조건으로 자동 이식할 수 없다.

명시적 후보 충돌 관계는 확인되지 않았다. Q01 색상, Q03의 나머지 옵션, Q04의 나머지 옵션을 R01/R02 지지나 충돌로 해석하지 않는다. Q07 이미지 회피도 해당 이미지의 회피 사실이며 후보 회피가 아니다. Q05~Q10 이미지·비교 메타데이터로 후보 의미를 임의 추론하지 않는다. 예를 들어 기존 Q08 비교 메타데이터는 AWAITING_VISUAL_DEFINITION이며 `candidateEvidenceMappings`가 비어 있다. 여성복 Q08 C04/C05·Q09 C02의 순위 또는 미선택을 사용하려면 **해당 정의 버전·그룹·옵션별로 R01/R02와의 관계**부터 승인해야 한다. 일반 다중선택의 미선택과 NONE은 후보 부정 근거로 만들지 않는다.

### 실제 옵션 계약에 맞춘 응답 예시

아래는 저장된 회원 데이터의 재현 결과가 아닌 계약 검토용 부분 응답 예시이다. 다른 필수 질문은 동일하게 유효 응답했다고 가정하며, 전체 제출용 payload나 실행한 테스트 결과가 아니다.

| Q02 선택 | 추가 실제 선택 | 두 후보 구별 여부 / 현재 판별 |
|---|---|---|
| R01, R02 | Q03 S02; Q04 P01 | 구별 불가. S02는 R01과 양립 가능하다는 제안뿐이며 P01은 공통. 둘 모두 DEFERRED |
| R01, R02 | Q03 S05; Q04 P01 | 구별 불가. S05가 R02 고유 조건이라는 승인이 없어 둘 모두 DEFERRED |
| R01, R02 | Q03 S02와 S05; Q04 P04 | 구별 불가. 지지 개수 비교·우선순위·후보 충돌을 만들지 않고 둘 모두 DEFERRED |
| R01 | Q03 S02; Q04 P01 | 초기 후보 R01만 생성. 후보가 하나여도 충분성 규칙이 없어 DEFERRED |
| R01, R02 | 여성복 Q08 C04에서 B→A 선택 | B 1위·A 2위 및 그룹 내 C 미선택 사실은 보존하되 후보 관계가 없어 둘 모두 DEFERRED |

다음 승인에는 사용할 질문·옵션의 후보별 지지/명시적 충돌/구별 관계, 적용 정의 버전, 충분한 관측 조합, 양쪽 조건 충족 또는 충돌 시 보류 조건이 필요하다. 위 S02/S05 등을 반드시 구별 조건으로 채택하자는 제안이 아니다. 현재 자료로 고유성을 확인할 수 없다면 사용하지 않고 검증 가능한 다른 관측을 지정해야 한다. 판별 로직은 변경하지 않았으므로 이번 작업에서는 Java 테스트를 추가하거나 재실행하지 않았다.
